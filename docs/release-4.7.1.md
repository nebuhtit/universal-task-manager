# 4.7.1 — надёжный Live Text и повторяющиеся задачи

- Исправлено падение при вводе `р` / `r` рядом с привязкой `rr` и неполными
  параметрами времени. Ошибки черновика показываются у поля, а не закрывают приложение.
- Проекты, области, теги и другие параметры Live Text сохраняются при редактировании
  из Home, Calendar и PARA. Начальная точка отключает команды; слова в кавычках
  остаются обычным текстом после повторного открытия редактора.
- После выбора `rr` можно одним действием добавить области, проекты и теги
  связанного item. Копирование выполняется только по явному выбору пользователя.
- Обычные новые задачи не получают начало и конец события автоматически:
  они завершаемые, с оценкой 10 минут. Создание на календарной шкале сохраняет
  выбранный временной слот. Удаление границы связанного события предлагает
  подтверждение отвязки и удаления события Google, сохраняя сам item.
- Изменения «This and all future occurrences», включая напоминания, применяются
  к будущим повторам без перезаписи их несвязанных индивидуальных изменений.
- Добавлены настройки ежемесячных повторов по дате, порядковому дню недели,
  полной или неполной календарной неделе, с пояснениями об активации и кодах длительности.
- Item с заданным active range не возвращается в Today как просроченный после
  окончания диапазона. Обычные просроченные задачи без диапазона остаются видимыми.
  Исправлен индикатор просрочки для точечного дедлайна в PARA.
- Обновлены стартовые фильтры Today и Non-specific и цвета Home Views.
  Пользовательские существующие виды не перезаписываются.

Формат рабочего пространства и резервных копий не меняется.
