# 4.6.8 — уведомления, запуск и погода

- Одноразовые предложения включить Face ID и локальные уведомления доступны в
  центре уведомлений. Подтверждение открывает отдельное окно выбора.
- Уведомления iOS сообщают состояние разрешения через нативный мост.
- Диагностика погоды фиксирует состояние кэша, загрузку прогноза, ошибки,
  длительность и восстановление соединения, не записывая город или координаты.
- Повторная загрузка погоды после ошибки ускорена и также запускается при
  восстановлении соединения или возвращении приложения на экран.
- Исправлена проверка сохранённой настройки Face ID при восстановлении доступа.
- Добавлен тестовый режим отключения шифрования локального хранилища с
  подтверждением создания резервной копии и последующим включением шифрования.
- Экран восстановления позволяет восстановить выбранную резервную копию как
  рабочее пространство после явного подтверждения.

Проверки перед выпуском: профильные Vitest и Playwright проверки, typecheck,
web build и iOS Simulator build пройдены. Физическое устройство не проверялось.
