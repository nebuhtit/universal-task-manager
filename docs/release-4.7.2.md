# 4.7.2 — устойчивый ввод и аккуратные резервные копии

- Подсказки Live Text в редакторе не сдвигают поле ввода и соседние разделы.
  Выбор с клавиатуры прокручивает только список подсказок.
- Исправлена обработка нажатий на варианты длительности и добавлен пресет 5 минут.
- Перенос областей, проектов, тегов и общего приоритета PARA требует удержания
  0,5 секунды. Раннее движение отменяет перенос и оставляет обычную прокрутку.
- Имена ручных резервных копий по умолчанию постоянные. В настройках добавлена
  выключенная галочка для версии приложения, формата workspace, даты и времени
  в имени файла. Выбор сохраняется на устройстве.
- Система Files предлагает заменить файл; браузер может создавать нумерованные
  копии вместо перезаписи. Формат резервных копий не изменён.

Изменения жестов заголовков Home Views и полноэкранного открытия в этот выпуск
не входят: область действия этого отдельного запроса ещё требует уточнения.
