# 4.6.6 — Live Text: связи и календари

- `рр` / `rr` сразу открывает подбор items. Закреплённые резервные блоки из календаря и Views, например Work, предлагаются первыми. Ввод букв сужает список.
- `кк` / `cc` открывает поиск доступных для записи Google-календарей. Выбор сохраняется по ID, отображается компактной меткой и синхронизирован с обычным полем Google Calendar в редакторе.
- Поддержка общая для нижней строки быстрого ввода, календаря, быстрого добавления в PARA, заголовка item и отдельной строки Quick entry.
- Названия календарей не участвуют в разборе дат и длительностей. Выбор календаря сам по себе не добавляет время события и не запускает отправку в Google; отправка следует обычному сохранению item.
- При открытии редактора подтверждённый перенос в Google обновляет выбор календаря. Незавершённый локальный перенос сохраняет целевой календарь из очереди отправки.
- Числовой `rr 30m` продолжает работать как прежнее сокращение будильника.

Проверка: разбор и сохранение данных, повторное открытие, порядок подсказок, права записи календарей, desktop Chromium и мобильный WebKit, отправка и перенос связанного Google-события через поддельный API. Проверка на физическом iPhone остаётся отдельным шагом.
