# Лаборатория текстового ввода UTM

Локальная лаборатория быстрого ввода. Её парсер используется приложением UTM при создании item; сама лабораторная страница не сохраняет карточки и не отправляет уведомления. Разбор не обращается к AI или сети. UI использует существующие React, примитивы и токены проекта. Сторонние реализации парсера не копировались.

Из корня репозитория:

```sh
bash apps/web/quick-entry-lab/run.sh
```

Открыть http://127.0.0.1:4187. Сервер привязан только к этому компьютеру. Сборка отдельная, без service worker UTM. Разбор работает без интернета после загрузки страницы; для повторного открытия нужен работающий локальный сервер.

```sh
bash apps/web/quick-entry-lab/run.sh check
# Пока сервер запущен, в другом терминале:
bash apps/web/quick-entry-lab/run.sh browser
```

`check` запускает тесты парсера, отдельный TypeScript check, production build и проверку whitespace. Browser-проверки используют Chromium на desktop и в мобильной эмуляции; это не проверка настоящего iPhone Safari/PWA. Результаты и скриншоты лежат в /tmp/utm-quick-entry-*.

## Поддерживаемая грамматика

Название может стоять до, после или между командами; порядок команд свободный. Парсер отделяет от названия самое длинное корректное значение каждой команды. Одна команда каждого типа, список напоминаний внутри одной команды через запятую.
Между частями записи можно ставить `;`, запятую или тире: `Стрижка; начало завтра 15:00; дорога 45м`. Запятая внутри названия (`Купить молоко, хлеб`) и плотного списка напоминаний (`выезд-1д,выезд-2ч`) сохраняется.

```text
Стрижка начало завтра 15:00 дорога 45м напомнить выезд-1д,выезд-2ч
Стрижка event opens tomorrow 15:00 tt 45m r leave-1d,leave-2h
Стрижка начало:завтра в 15 00 ехать 45 мин напомнить за день и 2 ч до выезда
Встреча начало завтра 15:00 длительность 1ч30м напомнить начало-30м
Позвонить напомнить через45м
Отчёт срок пятница
В магазин в след пт 14 22
Встреча с завтра 10:00 по завтра 11:00 срок пятница
Даша вс 15 00
Домашнее задание до вс 15 00
```

Алиасы: `длительность` / `duration`, `срок` / `due`, `начало` / `start`, `выезд` / `leave`, `через` / `in`. Двоеточия в командах не нужны; старый ввод с двоеточиями пока распознаётся. `след` — сокращение «следующий»: день следующей календарной недели. Даты: сегодня/today, завтра/tomorrow, послезавтра, русские/английские дни недели (в том числе пн/mon), DD.MM[.YYYY], YYYY-MM-DD. Время HH:MM; естественный шаблон также допускает «в 15 00». Длительности составные: `1ч30м`, `1h30m`; дроби через точку. Напоминания `1д` означают 24 часа, не календарный день.

В прототипе используется локальный часовой пояс браузера; он виден на странице. Если время не указано, используется 09:00. «Утром» означает 07:00, «днём»/«днем» — 11:00, «вечером» — 18:00, «ночью» — 21:00. Эти слова разбираются вместе с датой и не предлагаются как отдельные подсказки. День недели — ближайший, включая сегодня; `след пт` — пятница следующей календарной недели. Дата без года — текущий год, без автоматического переноса. Не существующие даты и часы отклоняются. DST-пропуск отклоняется; неоднозначный час при осеннем переводе использует стандартный выбор JavaScript Date (раннее вхождение). Полноценный выбор IANA timezone и разрешение неоднозначных часов — работа перед интеграцией.

Кавычки `"…"` и `«…»` защищают название от распознавания. Естественная речь поддерживает ограниченный шаблон примера, а не произвольные русские предложения. Повторения не поддерживаются. Ошибки блокируют карточку, прошедшее время предупреждает. Пустые `дорога:` и `длительность:` считаются очищенными необязательными полями. Подсказка даты сохраняет время, уже введённое справа. Варианты напоминаний до выезда появляются при заданной длительности дороги или явном упоминании выезда; пустая `дорога:` сама по себе их не включает. Опорное время фиксировано для изучения результата; кнопка обновляет его, создание заново разбирает текст с текущим временем.

## Интеграция с item

`parseEntry(text, now)` возвращает черновик и ошибки без побочных эффектов. `suggest(text, caret)` возвращает варианты и диапазон замены. При создании item краткое название попадает в `title`, а полный ввод с зафиксированными абсолютными датами — в `extensions['utm:quickEntrySource']`. В Edit item строку можно изменить и применить новый разбор. Экспорт UTM сохраняет расширение вместе с item.
Новые строки помечаются версией грамматики 2. При открытии старой строки без версии её неявная дата due получает явное `до`, если дата совпадает с сохранённым due item; само расписание при этом не сдвигается.

Для напоминаний от выезда исходная строка хранит anchor и offset; при изменении дороги в редакторе время такого напоминания пересчитывается. Автоматические тесты парсера сохраняются как контракт поведения.

Исходная база: 452cb85. Эксперимент — незакоммиченные изменения; версия приложения не менялась.

## Начало события по умолчанию и due через «до»

`Даша вс 15 00` задаёт event opens в воскресенье в 15:00, длительность 1 час и event ends в 16:00. `Домашнее задание до вс 15 00` задаёт только due в 15:00: без начала и конца, с оценкой длительности 10 минут. Явная `длительность` переопределяет эти значения. Начало можно также подписать `начало`, `start` или `event opens`; окончание — `конец`, `end` или `event ends`. Для due также работают прежние `срок`, `due` и `@`. Дата без времени получает 09:00. Дорога считается перед event opens.

Парный диапазон `с завтра 10:00 по завтра 11:00` задаёт только event opens и event ends; due остаётся отдельным `до` или `срок`. Неполная пара считается ошибкой, если после `с` или `по` указана дата. Обычные слова `с` и `по` в названии остаются текстом. Одинаковые начало и конец не допускаются.

`напомнить:30м,2ч` / `r:30m,2h` — автоматическая привязка: к event opens, если он есть; иначе к due. Порядок команд не влияет. Явные `r:due-30m`, `r:start-30m`, `r:leave-30m`, `r:in30m` не переключаются. Для относительного напоминания от due требуется время due.

При одновременно заданных длительности и event ends проверяется их согласованность. Окончание раньше начала — ошибка. Подсказки и карточка показывают текущую привязку напоминаний.

## Контекстные подсказки даты и времени

При редактировании даты доступны завтра, сегодня (только если выбранное время ещё впереди) и все семь дней недели с конкретными датами. Для уже прошедшего времени текущего дня недели вставляется дата следующей недели. Введённое время сохраняется; время без значения предлагает ближайшие варианты с шагом 15 минут. Пустые команды поддерживают подсказки и после пробела.
Если введён час без минут (`15:`), варианты идут в порядке `15:00`, `15:15`, `15:30`, `15:45`, затем остальные значения с шагом 5 минут. Введённый префикс минут фильтрует этот порядок: для `15:1` сначала предлагается `15:15`, затем `15:10`.

«Выбрать дату…» открывает нативный календарь браузера (`input type=date`, `showPicker`). После выбора заменяется только текущая дата со временем; последующие команды сохраняются. Если браузер не позволяет программно открыть календарь, остаётся видимое нативное поле даты.

## Ввод без пунктуации

Даты `завтра`, `среда`, `ср`, `23.09.2026`, `2026-09-23` распознаются без @; без времени используется 09:00. Поддерживаются все сокращения пн, вт, ср, чт, пт, сб, вс. Подписи начало, конец, срок, дорога, длительность, напомнить, напоминание, напоминания пишутся через пробел без двоеточия. Пример: `футбол чт 15 00 напоминание за 1 день и 2 часа`. Подсказки сохраняют этот стиль ввода. Буквальные названия с зарезервированными словами и датами следует заключать в кавычки.
