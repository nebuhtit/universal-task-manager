# 4.6.9 — подписи шкалы Timeline

- Метки часовых делений показывают только часы.
- Метка текущего времени сохраняет часы и минуты и получает непрозрачный
  скруглённый фон, чтобы отделяться от шкалы.
- Новые workspace создаются с шестью стартовыми Home Views: Inbox, Today,
  No date, Tomorrow, This week и All items. Все используют заданные фильтры
  завершимости и отображение Table; существующие workspace не меняются.
- Восстановленные из резервной копии серии Google Calendar сохраняют
  отдельные будущие повторы; они больше не сворачиваются в автозакрытую историю.
- Синхронизация восстанавливает связь такой серии по точному ID мастер-события,
  не создавая новую копию в Google. Исправлены коллизии старых ID повторов;
  заведомо преждевременные системные закрытия устраняются после подтверждения
  активного события Google с сохранением ручных завершений и учёта времени.
