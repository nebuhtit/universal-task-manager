# 4.7.0 — удобное перепланирование, восстановление повторов Google и настройки

- Для задач с датой без времени Reschedule использует тот же вид меню,
  что и Move Due: понятные варианты, дата справа и отдельный выбор своей даты.
  Время и Due при переносе таких задач не добавляются.

- Настройки пароля, запроса пароля при запуске и паролей старых копий объединены
  с Face ID / Touch ID в разделе Device unlock.
- Тестовые режимы, диагностика, технические сведения, Workspace versions
  и Custom fields собраны в свёрнутом разделе «Для разработчиков».
- Восстановленная из резервной копии серия Google сохраняет отдельные будущие
  повторы. При синхронизации связь восстанавливается по точному ID мастер-события
  после проверки Google; новые удалённые события при этом не создаются.
- Исправлены коллизии старых ID повторов и преждевременные системные закрытия.
  Ручные завершения и учёт времени сохраняются. Добавлены проверки повторной
  синхронизации, перезапуска и прерывания сохранения.
- Включены подготовленные улучшения 4.6.9: подписи Timeline только часами,
  непрозрачная метка текущего времени с минутами, стартовые Home Views в Table,
  настройка свободного времени (по умолчанию выключена), Due in в скриптах видов,
  улучшения значков, секций редакторов и ввода длительности.
- Ошибки скриптов скрыты на карточках и доступны в редакторе.
- В заголовке календаря отображается диапазон температуры через «·»;
  название месяца сокращено. Улучшена диагностика погоды.

Изменения используют существующий формат рабочего пространства и резервных копий.
